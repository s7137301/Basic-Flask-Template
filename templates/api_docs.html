Developer reference

ComputeMarket API

Programmatically discover compute capacity and submit reliable rental jobs through a predictable REST interface.

Authentication

Send your API credential with every request in the Authorization header as a Bearer Token.

Authorization: Bearer cm_live_your_token_here

Keep tokens private, rotate them regularly, and never expose them in browser-side code or public repositories.

Endpoints

GET /api/v1/hardware/available

Returns available GPU and CPU listings with pricing, queue state, and hardware specifications.

curl https://api.computemarket.example/api/v1/hardware/available \
  -H "Authorization: Bearer cm_live_your_token_here"
{
  "data": [
    {
      "listing_id": 42,
      "hardware": "NVIDIA RTX 4090 + AMD Ryzen 9 7950X",
      "hardware_type": "CPU + GPU",
      "ram_gb": 64,
      "hourly_price": 1.10,
      "queue_status": "active",
      "specs": {"benchmark_score": 9450, "availability": "available"}
    }
  ]
}

POST /api/v1/rentals/priority

Submits a priority compute job. Priority jobs bypass standard queues and are charged at four times the base compute cost.

import requests

response = requests.post(
    "https://api.computemarket.example/api/v1/rentals/priority",
    headers={"Authorization": "Bearer cm_live_your_token_here"},
    json={"listing_id": 42, "hours": 6}
)
print(response.json())
{
  "status": "accepted",
  "agreement_id": 108,
  "queue_status": "active",
  "is_priority": 1,
  "total_cost": 26.40,
  "escrow_status": "held"
}

Rate Limits

Requests are limited to 60 requests per minute per token. Responses include standard rate-limit headers so clients can back off gracefully.

X-RateLimit-Limit: 60
X-RateLimit-Remaining: 58
X-RateLimit-Reset: 1710000000
